# gantoine/homebrew-tap

Homebrew formulae for my projects.

```sh
brew install gantoine/tap/muxer
```

| Formula | What it is |
| --- | --- |
| `muxer` | Connects the [Muxer Android app](https://github.com/gantoine/muxer) to cmux on your Mac. Formerly `cmux-relay`; `brew upgrade` moves existing installs over. |

Formulae here are updated automatically when their project publishes a release.
