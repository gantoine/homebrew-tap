# gantoine/homebrew-tap

Homebrew formulae for my projects.

```sh
brew install gantoine/tap/cmux-relay
```

| Formula | What it is |
| --- | --- |
| `cmux-relay` | Connects the [cmux Android app](https://github.com/gantoine/cmux-android) to cmux on your Mac. |

Formulae here are updated automatically when their project publishes a release.
